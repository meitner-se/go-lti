# Security policy

go-lti signs identity tokens that tools trust and verifies messages that tools send, so we treat
vulnerabilities in it as urgent.

## Reporting a vulnerability

Please report it privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. Don't open a public issue or pull request for it.

Include what an attacker can do, the affected version or commit, and how to reproduce it. We will
acknowledge the report and keep you updated until a fix is released.

## Supported versions

Fixes go into the latest release. Until v1.0.0 there are no backports to older v0.x releases.
