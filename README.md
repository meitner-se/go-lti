# go-lti

LTI 1.3 and LTI Advantage for Go, for the platform side: the system that launches tools, such as an LMS.

Work in progress. The first release covers launches (the OIDC login flow and id_token), Deep Linking 2.0, Dynamic Registration 1.0 and the platform's OpenID configuration and JWKS. LTI 1.1 is not supported.
